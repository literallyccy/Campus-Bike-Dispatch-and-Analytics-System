# 校园共享单车调度分析系统

面向校园调度管理者的课程项目：统计研判、调运建议、人工修改、隔离模拟、确认执行与复盘。大数据处理采用 Spark SQL、日期分区 Parquet、MLlib 和 Structured Streaming。前端为管理决策入口。

## 数据边界

校园 v2 是模拟数据，227,514条清洗订单，观察期224,290条。模型预测成功借还量，不能等同全部潜在需求。校园底图、建筑轮廓来自交大地图，数据与运营收益未经现实校准。Citi Bike真实归档仅保留历史指标摘要，原始订单未随本仓库分发。

## 本地运行

建议 Python 3.10或3.11、Java 11或17。运行前确认 `java -version` 可用。Spark首次启动需要可用的本地回环网络。以下命令在仓库根目录执行：

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python scripts/prepare_data.py
python src/start_local_demo.py --run outputs/local_demo --config config/manager_state_v2.json --port 8871
```

打开 http://127.0.0.1:8871/v1/ 。启动器会在后台运行管理进程，日志在 `outputs/local_demo/`。再次使用同一命令复用已健康启动的实例。关闭时按该目录 `supervisor.json` 中的进程信息确认身份后终止对应管理进程，不要批量终止其他Spark进程。

首次使用新目录初始化独立状态；重启同一目录恢复状态。仓库不包含Mac当前会话的数据库、个人草稿和检查点。全新环境的完整浏览器运行尚未重新验收，不能将文件检查称作端到端验收。

## 随包内容

- `src/`：当前服务及其本地依赖、Spark处理、训练、评价、性能实验核心入口。
- `dashboard/v1/`、`dashboard/assets/`：当前前端、真实底图与建筑轮廓；无虚构界面。
- `config/`：当前v2管理配置与必要调度配置。
- `data/packed/`：原有v2订单和潜在需求的gzip压缩文件，准备脚本恢复原始内容，无需生成数据。
- `data/simulated/campus_v1/`：当前调度器仍引用的节点和运输图，保留此兼容依赖。
- `outputs/dispatch_models_v2/`：冻结借车/还车模型，含便携推理JSON与Spark原生模型。
- 其他选定 `outputs/`：界面必需的风险画像、时段回放、历史统计与指标摘要。
- `FILE_MANIFEST.json`：打包内容的SHA-256校验清单。

未收录历史台账、验收记录、辅助验证脚本、学习材料和答辩文件。模型沿用已有权重，未重新训练。需要开发训练或评价时先阅读对应脚本 `--help`，部分脚本默认v1路径，使用v2需显式指定输入、模型及新输出目录。

## 已有结果与限制

正式14日模拟窗口共同潜在需求61,917次。不调度、固定、历史、模型策略未满足次数分别3,084、3,032、1,639、1,552，模型方案运输投入也更高。逐日保留6条相对不调度的负改善。借车MAE优势的2日块95%区间跨零，不能宣称显著改善。测试结果已被查看，不再据此调参。

既有UTM单虚拟机内两工作容器完成YARN任务，不是物理多机。应用计算成功和包装进程收尾超时分别记录。这里保留核心代码，不包含可直接一键重建原UTM的环境承诺。
