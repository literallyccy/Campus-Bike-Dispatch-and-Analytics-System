# 校园共享单车数据处理与调度分析

当前聊天取得的最新版源码。包含 Spark SQL 清洗与特征、MLlib 训练及推理、四策略模拟评价、流处理与调度工作台。校园订单为模拟数据，采用真实校园地图。

## 目录
- src/：核心处理、预测、模拟和服务代码。保留被核心模块导入的依赖，不包含验收脚本与学习练习。
- dashboard/：当前 v1 路径下的实际运营前端、地图和第三方资源。v1 是现有 URL 路径，不代表旧界面。
- config/：现有运行与评价配置。部分配置名含 v1，是当前代码仍使用的名称。

## 数据与模型
本包不包含正式订单数据、已训练模型权重或运行数据库。使用时从 Mac 原项目补入 data/ 和配置指向的已有模型、预测及运行资源，复用现有环境。未对本精简包作完整运行验证。

已有实例的启动入口：src/start_local_demo.py。保留本机已使用的 --run 与 --config 参数，端口8871，访问 http://127.0.0.1:8871/v1/ 。不要用缺少正式资源的包覆盖本机项目。

本包仅保留当前核心源码，没有历史文档、验收记录、辅助验证脚本、PPT或PDF。尚未上传GitHub。
